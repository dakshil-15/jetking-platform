🔧 TECHNICAL IMPLEMENTATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Selector Hierarchy
  1. :root { --theme-*: light values }
  2. .dark { --theme-*: dark values }
  3. .student-page { --stu-*: var(--theme-*) }
  4. .blog-page { --blog-*: var(--theme-*) }
  5. .centres-page { --centres-*: var(--theme-*) }
  6. ... (all pages use global variables)

Theme Switch Flow
  User clicks toggle button in header
           ↓
  toggleTheme() → localStorage.setItem()
           ↓
  Theme provider → emits change event
           ↓
  <html> class updated (add/remove .dark)
           ↓
  CSS cascade picks :root or .dark variables
           ↓
  All --theme-* variables re-evaluate
           ↓
  Entire page instantly updates colors
